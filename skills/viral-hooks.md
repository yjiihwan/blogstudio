# viral-hooks — 첫 문장(훅) 강화

독자가 첫 2초에 이탈하지 않도록 **도입부 첫 1~2문장**을 진단하고 강한 훅으로 교체한다.
글 전체가 아니라 **오프닝만** 손대는 국소 패스다.

> 벤치마크: 공개 훅 스킬들은 단일 문장 교체가 아니라 **유형별 다수 후보를 생성**해 고르게 한다
> (provocative/story/data-driven/contrarian 등). 우리도 **훅 유형별 N개 후보를 만들어 최적 1개를
> 선택·나머지는 대안으로 노출**하도록 확장한다. 반자동 화면에서 사용자가 후보 중 고를 수 있게 한다.

## 트리거 (언제 발동)

- 첫 문장이 약한 도입일 때:
  - 인사·자기소개("안녕하세요 ○○입니다").
  - 일반론·당연한 말("건강은 중요합니다", "요즘 ~가 대세죠").
  - 메타 발화("오늘은 ~를 소개하려 합니다").
  - 주제를 빙 둘러 뜸 들이는 서론.
- 파이프라인상 voice-dna 뒤(훅이 최종 톤과 어울리도록).

## 훅 유형 (후보 생성용 팔레트)

각 유형은 서로 다른 심리 지렛대를 쓴다. 진단 후 **글 소재로 성립 가능한 유형만** 골라 후보를 만든다.

| 유형 | 지렛대 | 예 |
|---|---|---|
| **장면형(scene)** | 즉시 몰입 | "저녁 8시, 러닝머신 20대가 다 찼다." |
| **문제직격형(problem)** | 독자 자기투영 | "PT 끊고 3번 만에 안 나간 적 있다면." |
| **데이터형(data)** | 신뢰·의외성 | "3개월 등록자의 절반이 첫 2주에 갈린다." (확정 사실만) |
| **역설/반전형(contrarian)** | 통념 뒤집기 | "운동은 많이 할수록 손해일 때가 있다." |
| **도발/질문형(provocative)** | 긴장·궁금증 | "왜 같은 3개월인데 결과가 갈릴까?" |
| **스토리형(story)** | 서사 진입 | "리포머 위에서 5분 만에 다리가 후들거렸다." (storytelling 도입 승격) |

## 동작 — 다수 후보 생성 → 선택

1. **진단**: 현재 첫 문장의 약한 유형(인사/일반론/메타/뜸들이기)을 판정.
2. **후보 생성**: 성립 가능한 훅 유형마다 **1~2개씩, 총 3~5개 후보**를 만든다. 모든 후보는 **확정 사실·
   감각·독자 관점**에서만 만든다(없는 사실·수치 금지).
3. **선택**: 자동 모드는 아래 선정 기준으로 1개를 골라 본문에 적용하고, 나머지를 `notes.alternatives`에
   담는다. 반자동 화면은 후보 전체를 사용자에게 노출해 고르게 한다.
4. **접합 확인**: 선택한 훅의 둘째 문장·본문 서사(storytelling)로 매끄럽게 이어지는지 점검.

### 후보 선정 기준(자동 모드)
- 글 소재와의 밀착도(있는 사실을 얼마나 살렸나) > 톤 적합(voice-dna 프로필과 어울림) > 진부하지 않음.
- 데이터형은 **확정 수치가 실제로 있을 때만** 후보에 넣는다(없으면 생성 금지 → 유형 제외).

## 규칙

### DO
- 유형별 후보를 3~5개 생성하고, 그중 하나를 본문 첫 문장으로 확정한다.
- 훅은 **확정 사실·감각·독자 관점**에서만 만든다.
- 훅이 본문 서사(storytelling)로 매끄럽게 이어지는지 확인한다.
- 훅의 말투는 voice-dna로 정해진 톤(프로필)을 따른다.
- 선택되지 않은 후보를 `notes`에 남겨(대안) 검수·반자동 선택에 쓴다.

### DON'T
- 낚시·과장으로 훅을 만들지 않는다("믿기 힘든 충격 결과!", "이것 모르면 손해").
- 없는 사실·수치·사건을 지어내 훅으로 쓰지 않는다(전역 0번 규칙). → 데이터형은 근거 없으면 후보 제외.
- 본문 전체를 건드리지 않는다(이 스킬은 도입부 국소 수정).
- 첫 문장 교체로 뒤 문단과 문맥이 끊기게 두지 않는다.
- anti-ai가 잡는 상투 표현으로 훅을 만들지 않는다(예: "요즘 ~가 대세죠").

## 적용 전후 예시

**전**
> 안녕하세요! 오늘은 강남 필라테스 센터를 소개해 드리려고 합니다.
> 요즘 필라테스가 정말 인기가 많죠.

**후보(생성)**
- 장면형: "리포머 위에서 5분 만에 다리가 후들거렸다."
- 문제직격형: "필라테스, 유연한 사람만 하는 운동이라 생각했다면."
- 도발/질문형: "운동을 안 한 것도 아닌데 왜 기구 필라테스는 이렇게 다를까?"

**후(선택 = 장면형)**
> "리포머 위에서 5분 만에 다리가 후들거렸다."
> 운동을 안 한 건 아니었는데, 기구 필라테스는 처음이라 근육이 쓰이는 자리가 완전히 달랐다.

## 통과 체크리스트

- [ ] 훅 후보가 3~5개 생성됐고, 미선택 후보가 `notes.alternatives`에 있다.
- [ ] 첫 문장이 인사·일반론·메타발화가 아니다.
- [ ] 선택된 훅이 유형(장면/문제/데이터/역설/도발/스토리) 중 하나다.
- [ ] 낚시·과장 표현 없음. anti-ai 상투 표현 없음.
- [ ] 새로 지어낸 사실 0개(확정 사실/감각/독자관점만). 데이터형은 실제 수치 있을 때만.
- [ ] 훅→둘째 문장→본문 문맥이 끊기지 않는다.
- [ ] 도입부 외 본문은 변경되지 않았다.

## 입출력 (엔진 배선)

```ts
// 입력
{ draftMd, persona, options?: {
    hookStyle?: "scene" | "problem" | "data" | "contrarian" | "provocative" | "story" | "auto"; // 기본 auto
    candidateCount?: number;  // 생성 후보 수(기본 4, 3~5 권장)
} }
// 출력
{ revisedMd, changes,  // changes[0] = 교체된 첫 문장 before/after
  notes: string[]      // 진단한 약한 도입부 유형 + 선택 훅 유형
    // + alternatives: { style, text }[]  ← 미선택 후보(반자동 선택/검수용)
}
```
