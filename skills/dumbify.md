# dumbify — 쉬운 말로 재작성

어려운 문장을 **중학생도 한 번에 이해할** 쉬운 말로 바꾼다. 전문용어를 풀고,
긴 문장을 짧게 끊는다. 파이프라인 **맨 마지막** 가독성 패스다.

## 트리거 (언제 발동)

- 설명 없이 던져지는 전문용어·업계 약어(예: "인바디", "가동범위", "PT 세션 밀도").
- 한 문장이 40자를 크게 넘겨 숨이 차는 만연체.
- 한자어·번역투가 겹쳐 뜻이 안 잡히는 문장.
- 이중부정·수동태·명사화가 겹친 문장.
- 파이프라인상 최종 단계(뒤 단계가 되돌리지 않도록).

## 규칙

### DO
- 전문용어는 **처음 나올 때 쉬운 말로 풀어준다**(용어 자체를 지워도 되고, 괄호로 짧게 설명해도 됨).
- 긴 문장을 두세 문장으로 끊는다(한 문장 = 한 가지 뜻).
- 어려운 한자어를 일상어로 바꾼다("가동범위" → "관절이 움직이는 범위").
- 수동태·이중부정을 능동·긍정으로 편다("이용이 불가하지 않다" → "쓸 수 있다").

### DON'T
- 쉬운 말로 바꾸며 의미·뉘앙스·확정 사실을 왜곡하지 않는다.
- 유아어·과한 반말로 격식을 무너뜨리지 않는다(voice-dna 톤 유지).
- 상호·고유명사·확정 수치·이미지 마커를 단순화한다는 명목으로 삭제하지 않는다.
- 없는 예시·비유를 사실인 것처럼 지어내지 않는다(전역 0번 규칙; 비유는 비유로 표시).
- 앞 단계(anti-ai·voice-dna·hooks)가 만든 결과를 뭉개지 않는다(문장만 쉽게, 구조·톤·훅 보존).

## anti-ai 리듬 다양화와의 정합 (충돌 방지)

dumbify는 문장을 **짧게 끊어** 쉽게 만든다. anti-ai(C-15)는 **문장 길이가 균일하면** 튄다고 본다.
둘 다 "짧게"를 지향하지만 **전부 균일하게 짧아지면** 오히려 AI티가 난다. 정합 원칙:

- 긴 만연체는 끊되, **결과가 3~4문장 연속 같은 길이·같은 종결어미가 되지 않게** 한다(짧은 문장 사이에
  중간 길이 문장 하나를 섞어 리듬을 남긴다).
- dumbify는 맨 마지막 패스다 → **앞서 anti-ai가 만든 리듬 변주와 voice-dna 어미 믹스를 뭉개지 않는다**
  (DON'T에 명시). 뜻을 못 잡는 문장만 손대고, 이미 쉬운 문장은 건드리지 않는다.
- 공개팩은 dumbify 대응물이 약하다 → 우리 **차별점**. 위 정합만 지키면 anti-ai·voice-dna와 공존.

## 적용 전후 예시

**전**
> 본 센터는 회원의 신체 조성 데이터를 기반으로 개인별 가동범위와 근피로도를 고려한
> 맞춤형 저항 트레이닝 프로토콜을 제공함으로써 부상 리스크를 최소화하고자 합니다.

**후**
> 이 센터는 먼저 몸 상태를 재봅니다(체지방·근육량 측정).
> 그 결과에 맞춰 관절이 움직이는 범위와 그날의 피로도를 보고 운동 강도를 정합니다.
> 무리하게 시키지 않아서 다칠 위험이 적습니다.

## 통과 체크리스트

- [ ] 설명 없는 전문용어 0개(모두 풀거나 짧게 설명).
- [ ] 한 문장이 대체로 짧다(만연체 해소).
- [ ] 수동태·이중부정이 능동·긍정으로 정리됐다.
- [ ] 의미·확정 사실이 왜곡되지 않았다.
- [ ] voice-dna 톤·viral-hooks 첫 문장·storytelling 구조가 보존됐다.
- [ ] 상호·고유명사·수치·이미지 마커 보존.

## 입출력 (엔진 배선)

```ts
// 입력
{ draftMd, persona, options?: {
    targetGrade?: "middle_school" | "high_school"; // 기본 middle_school
    keepTermInParen?: boolean;  // 전문용어를 괄호 설명으로 남길지(기본 true)
} }
// 출력
{ revisedMd, changes, notes? }  // 공통 SkillResult
```
